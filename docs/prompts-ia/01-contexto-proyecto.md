# Contexto del proyecto

## Caso 02 – Generador Inteligente de Reclamos de Consumo

El proyecto **Generador Inteligente de Reclamos de Consumo** se desarrolla como parte del Seminario de Ingeniería de Software con Inteligencia Artificial Generativa de la Universidad Regional Autónoma de los Andes (UNIANDES).

El propósito del proyecto es diseñar una solución informática que facilite a los consumidores ecuatorianos la elaboración de reclamos relacionados con productos o servicios, mediante el uso de inteligencia artificial generativa y la consulta de fuentes normativas verificables.

El sistema permitirá que el consumidor describa su problema en lenguaje natural. A partir de esta información, se identificarán los hechos relevantes, los datos faltantes o contradictorios y los posibles fundamentos normativos aplicables.

La solución contempla técnicas de generación aumentada por recuperación (RAG) para consultar documentación normativa, evitando que la inteligencia artificial genere referencias legales sin respaldo.

El usuario podrá revisar la información obtenida y autorizar expresamente la generación de un borrador de reclamo. El sistema no realizará presentaciones automáticas ante instituciones públicas.

Como parte del análisis inicial, se requiere elaborar un documento de especificación de requisitos que incluya necesidades identificadas, requisitos funcionales y no funcionales, reglas de negocio, historias de usuario y criterios de aceptación verificables.

Para apoyar esta actividad se utilizará OpenAI Codex mediante instrucciones estructuradas que permitan generar documentación coherente, verificable y alineada con el alcance académico del proyecto.

### Tecnologías previstas

- Frontend: React y TypeScript.
- Backend: Java y Spring Boot.
- Integración con IA: Spring AI.
- Recuperación documental: ChromaDB y RAG.
- Persistencia: SQLite.

**Estado del proyecto:** fase de análisis y diseño de requisitos; no se asumen funcionalidades implementadas.
